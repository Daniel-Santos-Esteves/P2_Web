
# Bairro em Ação

## Sobre o projeto

O Bairro em Ação é uma plataforma de Tecnologia Cidadã
que permite aos moradores registrar problemas encontrados
em seus bairros.

O objetivo é incentivar a participação da população
na identificação de problemas urbanos.

## Problema identificado

Moradores podem encontrar dificuldades para comunicar
problemas de infraestrutura, como buracos nas ruas,
iluminação defeituosa e acúmulo de lixo.

## Público-alvo

Moradores de bairros urbanos que desejam colaborar
com a melhoria dos espaços públicos.

## Objetivos de Desenvolvimento Sustentável

- ODS 9: Indústria, inovação e infraestrutura.
- ODS 11: Cidades e comunidades sustentáveis.
- ODS 16: Paz, justiça e instituições eficazes.

## Funcionalidades

- Cadastro de problemas.
- Listagem de registros.
- Edição de registros.
- Exclusão de registros.
- Histórico de atividades.
- Filtro por categoria.
- Armazenamento local.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Git
- GitHub

## Modelo de negócio de impacto

A plataforma poderá ser oferecida como serviço
para associações de moradores, organizações sociais
e administrações municipais.

A sustentabilidade financeira poderá ocorrer por
meio de contratos de implantação, hospedagem,
suporte e manutenção.

O acesso dos moradores poderá permanecer gratuito.

## Segurança: três ameaças e mitigações

1. Injeção de código (XSS):
   Utilizar textContent para exibir dados e validar
   as informações recebidas.

2. Exposição de dados pessoais:
   Coletar somente informações necessárias e orientar
   os usuários a não informar dados pessoais.

3. Registros falsos ou vandalismo:
   Uma versão real poderá utilizar autenticação,
   moderação e limites de envio.

## Privacidade

O protótipo utiliza localStorage para armazenar
os registros no navegador.

Não existe envio de dados para um servidor.

Devem ser utilizados apenas dados fictícios
ou abertos durante a demonstração.

## Limitações

O protótipo não envia solicitações à prefeitura,
não possui autenticação e não sincroniza registros
entre diferentes usuários.
